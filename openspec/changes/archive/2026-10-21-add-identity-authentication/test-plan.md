# Test plan: add-identity-authentication

## How to run a named test

Tests are named `file › describe › test`. Run one from its project directory with Vitest's name filter:

- unit (`test` target): `cd apps/api && npx vitest run <file> -t "<test name>"` (likewise `libs/shared/domain`, `tools/delivery`; `libs/identity/infrastructure` once the project exists)
- integration: `pnpm nx run api:build`, then `cd apps/api && npx vitest run -c vitest.integration.config.mts <file> -t "<test name>"` (needs Docker)
- end-to-end: `pnpm nx run api:build`, then `cd apps/api-e2e && npx vitest run -c vitest.e2e.config.mts <file> -t "<test name>"`
- type-level assertions run under `pnpm nx typecheck <project>`, not under `test`

Put `~/.nvm/versions/node/v24.9.0/bin` first on `PATH`.
